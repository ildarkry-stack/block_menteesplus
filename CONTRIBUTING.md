# Contributing

Use Moodle coding style, `moodle-plugin-ci`, separate permissions for view/edit, and tests for both valid and forged student/course IDs. Never broaden grading access as a workaround. Test clean install and upgrades on Moodle 5.0, 5.1 and 5.2, including PHP lint, PHPCS, PHPUnit, capability checks and course grade updates.
